# Iota
Mobdev group project

##  Overview

This app is inspired by the book Atomic Habits and is designed to help users build meaningful habits while reducing unnecessary phone usage. It encourages intentional living by aligning daily actions with the identity the user wants to become.

The goal is simple:
** Use your phone less, focus more, and become who you want to be.**

## Core Philosophy

The app follows a structured habit-building journey:

1. Identify the identity you want to become
   (e.g., "I want to become a disciplined person")
3. Decide when and where you will act
   (clear time and context for your habits)
4. Define the habit actions
   (what you will consistently do to reinforce that identity)
5. 21-Day Milestone
   Users begin to notice meaningful changes
6. 66-Day Completion
   The habit becomes natural — no external restriction needed
👉 The habit cycle officially ends here

## App Flow

Users progress through a guided system:

Identity selection → Habit creation → Daily tracking → Reflection → Habit completion

## Home Tab Features
1. Habit Dashboard
Displays all active habits tied to your chosen identity using “habit pebbles”
2. Create New Habit
Users can create up to 6 habits per identity
3. Habit Logging
Long press (2 seconds) on a habit pebble to log completion

## Focus Tab (App Blocking Feature)

For users who need stronger discipline:

- Select apps you want to avoid
- The app will block access temporarily
- Displays a message like:
"Come back at 4:00 PM"

This feature helps reduce distractions and reinforces intentional usage.

## Key Goals
- Build long-term habits through identity-based growth
- Reduce screen time and distractions
- Encourage consistency over perfection
- Provide gentle accountability with optional strict controls
